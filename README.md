# Ripple interactive demo

An iPhone-layout interactive demo built from `design-references/Ripple_Demo_Design_Spec_EN.md`.

## Demo entry

- Enter any valid-looking phone number.
- Use verification code `123456`.
- Allow Contacts continues registration; Don't Allow demonstrates the required blocking state.

## Main flows

- Discover: Poster Board, Map, My Plans, details, join, group chat.
- Create: form, poster generation, preview, publish, My Posts, editor.
- Chats: activity-group list, suggested replies, sending messages, cancelled read-only example.

## Run locally

Use the project package scripts: `pnpm dev` for development and `pnpm build` for a production check.

All original source references are preserved in `design-references/` for future iterations.
